# Playwright QA Automation Framework

This repository contains an automated end-to-end testing suite structured around the **Page Object Model (POM)** design pattern.

## 🛠️ Prerequisites
Before running the tests, ensure you have [Node.js](https://nodejs.org) installed on your machine.

## 🚀 Setup Instructions
1. Clone this repository or download the source files.
2. Open your terminal in the project directory and install the required tracking dependencies:
   ```bash
   npm install
   ```
3. Install the Playwright test browsers:
   ```bash
   npx playwright install
   ```

## 🧪 Executing the Tests
To trigger the complete test automation suite, run the following command:
```bash
npx playwright test
```
